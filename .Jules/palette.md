## 2024-05-24 - Custom Select Accessibility\n**Learning:** Custom dropdown components built with basic HTML often lack proper screen reader context (listbox/option roles) and visible focus states for keyboard users.\n**Action:** Always add WAI-ARIA roles (`listbox`, `option`), attributes (`aria-haspopup`, `aria-expanded`, `aria-selected`), and `focus-visible` utility classes to custom interactive components to ensure full accessibility.
