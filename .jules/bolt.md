## 2024-05-24 - Unmemoized Object Props Breaking Animation Loops
**Learning:** In React, if a parent component updates frequently (e.g. tracking `currentTime` during audio playback multiple times a second), passing an unmemoized object like `{ left: node, right: node }` as a prop to a child component (like `AudioVisualizer`) causes the child to constantly re-render. If the child manages an animation loop (like `requestAnimationFrame`), the changing object reference causes `useCallback` and `useEffect` dependencies to re-evaluate, constantly cancelling and restarting the animation loop, leading to severe micro-stutters and wasted cycles.
**Action:** Always memoize object props (`useMemo`) passed to performance-sensitive child components (especially those running animation loops or heavy renders), and wrap the child component in `React.memo` to isolate it from the parent's frequent unrelated state updates.
